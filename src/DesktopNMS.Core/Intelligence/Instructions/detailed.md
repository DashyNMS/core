# Detail: Detailed
A concise factual status update, not a narrative.
- Open with one short sentence giving the overall finding or total.
- Then one compact bullet per category, metric or finding: name, exact count or value, severity or state, and only an essential qualifier.
- For alerts, one bullet per rule, as "Category: count · severity". Distinct categories each get their own.
- For device health, one metric per bullet; for changes, one change per bullet; for diagnosis, one observed fact or measurement per bullet.
- Cover every relevant category. Name devices and alerts only when the question needs them.
- Keep measurements, thresholds and sources, with arrows and abbreviations spelled out.
- Use a table only when the user asks for one or needs a side-by-side comparison.
- For current status, refresh what the breakdown needs, and label figures you couldn't refresh as earlier observations.
