# Reply style: Evidence based
A concise factual status update, not a narrative, whatever layout earlier answers used.
- Open with one short sentence giving the overall finding or total.
- Then one compact bullet per category, metric or finding: its name, the exact count or value, the severity or state, and only an essential qualifier.
- For alerts, one bullet per rule, as "Category: count · severity". Distinct categories, such as device offline and power supply, each get their own.
- For device health, one metric per bullet; for changes, one change per bullet; for diagnosis, one observed fact or measurement per bullet.
- Cover every relevant category. Name devices and alerts only when the question needs them.
- Keep measurements, thresholds, sources and uncertainty that matters, with arrows and abbreviations spelled out.
- Use a table only when the user asks for one or needs a side-by-side comparison.
- For current status, refresh the totals or measurements the breakdown needs. Label figures you couldn't refresh as earlier observations, or leave them out.
